# 镜观开发说明

生成日期：2026-09-24

## 已有入口

### 配置

```python
from jinguan import JinguanConfig

config = JinguanConfig.from_env()
```

默认路径：

- 数据库：`database/jinguan.sqlite3`
- 数据根目录：`data/`
- 缓存目录：`.cache/`

也可以通过环境变量覆盖：

- `JINGUAN_DATABASE_URL=sqlite:///...`
- `JINGUAN_DATA_ROOT=...`
- `JINGUAN_CACHE_ROOT=...`
- `JINGUAN_REQUIRE_DATA_MOUNT=true|false`

### Repository

```python
from jinguan.repository import SQLiteRepository

repo = SQLiteRepository("database/jinguan.sqlite3")
paper_id = repo.create_paper(title="Example")
run_id = repo.create_run(
    paper_id=paper_id,
    schema_id="schema_geochemistry_v1",
    source_type="manual",
)
```

Repository 负责所有数据库写入，后续 Pipeline 模块不要直接散落 `sqlite3.execute(...)`。

### ArtifactStore

```python
from jinguan.artifact_store import LocalArtifactStore

store = LocalArtifactStore("data")
stored = store.save_json("work/run_demo/parsed.json", {"ok": True})
```

数据库只保存 `storage_key`，例如：

```text
work/run_demo/parsed.json
```

不保存绝对路径。

### 本地 PDF 导入

```python
from jinguan.artifact_store import LocalArtifactStore
from jinguan.pipeline import import_local_pdf
from jinguan.repository import SQLiteRepository

repo = SQLiteRepository("database/jinguan.sqlite3")
store = LocalArtifactStore("data")

result = import_local_pdf(
    pdf_path="example.pdf",
    repository=repo,
    artifact_store=store,
    title="Example Paper",
)
```

会完成：

- 校验 PDF 头
- 计算 SHA-256
- 保存到 `raw/pdfs/sha256/<前两位>/<sha256>.pdf`
- 写入 `papers`
- 写入 `pdf_assets`
- 创建 `runs`
- 写入 `run_events`
